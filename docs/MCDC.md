## Placing the original drawings

The section is built so that the November 20, 2024 drawings drop in without code changes:

| File (in `assets/mcdc/`) | What it is | Used for |
|---|---|---|
| `winged-wheel.png` | Winged wheel, red ink on the original cream stock, cropped tight | Program cover |
| `winged-wheel-line.png` | Same drawing as white line art on transparent | Wheel patch, back piece |
| `crossed-flags-line.png` | Crossed flags, white line art on transparent | Flags patch |
| `go-line.png` | The speed-lined GO, white line art on transparent | GO patch |
| `drawings-2024-11-20.jpg` | The full drawing sheet | "Where it started" |

Then set the matching key to `true` in `assets/mcdc/manifest.json`. Until then each slot shows a labelled stand-in, and no missing file is requested. Upload the original sheets anywhere in the repo and the cut-outs can be made from them.
