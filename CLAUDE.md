# Claude — Joseph Martin Repository Instructions

## Mandatory creative direction
**Before any design, UI, layout, copy, homepage, product, or collaboration work, read [docs/CREATIVE_DIRECTION.md](docs/CREATIVE_DIRECTION.md).** It is the governing art direction for this repository, approved 23 November 2026.

**North star:** An American hatmaker with the refinement of a global luxury house. Range Rover restraint, watchmaker precision, American craftsmanship and humanity. The approved benchmark is **Study B — The Object**: whiskey-brown and ivory, widely tracked JOSEPH MARTIN wordmark, fine annotated hat drawing, oversized confident product typography, disciplined navigation and considered material swatches.

### Default workflow
1. Read the guide and inspect the relevant existing page, assets and components.
2. Define the page's purpose and how it extends Study B's language.
3. Make the **smallest elegant improvement** that accomplishes the goal.
4. Show one coherent option by default; don't generate unrelated concepts unless asked.
5. Verify both desktop and mobile before reporting completion.
6. Never assume that visual approval validates speculative pricing, technical details or copy.

### Hard no
Generic AI design slop; random aesthetic pivots; kitschy Western styling; synthetic/filler imagery; invented claims; trendy gradients/cards; showy interaction experiments; gratuitous 3D; sprawling concept sets; refactoring approved work without purpose.

**If an idea contradicts the guide, stop and explain the tradeoff rather than silently implementing it.** Explicit user instructions can change the direction, but do not infer a change from a loose inspiration reference.

The purpose of this file is to make the approved standard durable across fresh Claude sessions and future redesign work.
